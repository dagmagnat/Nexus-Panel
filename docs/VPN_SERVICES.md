# Отдельные VPN-сервисы (Stage78)

Раздел **VPN-сервисы** управляет системными WireGuard, AmneziaWG и Outline отдельно от 3x-ui/Xray. Существующие узлы, inbound и подписки 3x-ui не изменяются.

## Подключение VPS

Для сервера агрегатора и стороннего VPS используется одинаковая безопасная схема: SSH к операционной системе хоста.

Доступны два способа входа:

- SSH-пользователь и пароль;
- приватный SSH-ключ, при необходимости с passphrase.

Для пользователя без root можно указать пароль sudo. После первой успешной проверки панель сохраняет SHA-256 fingerprint SSH host key. При последующих подключениях изменившийся fingerprint блокирует выполнение команд.

Все пароли, приватные ключи, API URL, клиентские конфигурации и резервные копии шифруются через `APP_SECRET`. При переносе панели необходимо сохранить прежний `APP_SECRET`, иначе расшифровать эти данные будет невозможно.

## Сервисы

- **WireGuard** — системный `wg`/`wg-quick`, отдельный интерфейс, UDP-порт и IPv4-подсеть.
- **AmneziaWG Legacy** — отдельный AWG-интерфейс с конфигурацией семейства 1.x.
- **AmneziaWG 2.0** — отдельный AWG-интерфейс с диапазонами H1–H4. Это не преобразование Legacy-файла, а самостоятельный сервис и набор ключей.
- **Outline** — официальный сервер Outline/Shadowbox и его Management API.

На одном VPS можно создать несколько сервисов, если интерфейсы, подсети и порты не пересекаются.

## Клиенты

VPN-клиент можно связать с существующим клиентом агрегатора либо оставить самостоятельным. Доступны:

- скачивание `.conf` для WireGuard/AmneziaWG;
- скачивание access key Outline;
- QR-код;
- включение и отключение;
- срок 1–3650 дней либо `0` для бессрочного доступа; продление — минимум на 30 дней;
- продление и удаление.

Истекший клиент автоматически отключается. После продления клиент, отключенный именно по сроку, включается снова.

## Резервные копии

Рабочие файлы остаются на VPS. После установки и изменения клиентов агрегатор сохраняет зашифрованный снимок конфигурации сервиса в собственной SQLite-базе. Общий экспорт backup панели включает таблицы `vpn_hosts`, `vpn_services`, `vpn_clients` и `vpn_jobs`.

## Ограничения первой сборки

- Реальная установка зависит от дистрибутива, ядра, DKMS, firewall и доступности репозиториев на конкретном VPS.
- Удаление карточки сервиса из агрегатора намеренно не удаляет пакеты и системные файлы с VPS.
- Временные публичные ссылки на конфигурации и полноценное восстановление сервиса из сохраненного снимка запланированы отдельным этапом.

Переустановка уже установленного WireGuard/AmneziaWG/Outline блокируется, пока в сервисе есть клиенты: это защищает активные peer и ключи от случайной перезаписи.
## Изменения Stage78

### Размещение

При добавлении VPS доступны два режима:

- **Сервер агрегатора** — публичный IP/домен заполняется автоматически, SSH-логин и пароль не запрашиваются. Установщик создаёт пользователя `aggvpn`, локальный Ed25519-ключ и ограниченное sudo-правило.
- **Сторонний VPS** — вход по SSH-паролю либо приватному ключу с необязательной passphrase.

### Общие параметры сервиса

В карточке сервиса редактируются имя, клиентский endpoint, порт, DNS и MTU. Для WireGuard и AmneziaWG изменение endpoint/DNS/MTU обновляет сохранённые клиентские конфигурации. При смене UDP-порта новый порт записывается в серверную конфигурацию, а старый сохраняется через совместимое перенаправление. При возврате на прежний порт конфликтующее перенаправление удаляется; при переносе на другой VPS сохранённые совместимые порты создаются заново.

### Домены

Кнопка **Проверить домен** разрешает клиентский endpoint через DNS и сравнивает его с публичным адресом выбранного VPS. Результат и найденные IP сохраняются в базе. Для независимой проверки в карточке VPS желательно указывать именно публичный IP.

### Клиенты

VPN-клиенты находятся на странице **Клиенты** в отдельных вкладках WireGuard, AmneziaWG и Outline. В каждой вкладке доступны создание на установленном сервисе, автоматический поиск, QR-код, скачивание конфигурации, переименование, срок, включение/отключение и удаление.

### Перенос на другой VPS

В карточке установленного сервиса можно выбрать другой VPS. Агрегатор проверяет SSH и конфликты, устанавливает сервис и восстанавливает клиентов из локально сохранённых ключей. Для WireGuard/AmneziaWG сохраняются прежние серверный и клиентские ключи, поэтому при неизменном домене клиентские конфигурации могут продолжить работу после переключения DNS. Для Outline ключи пересоздаются, поэтому клиентам потребуется получить обновлённый access key. Старый сервер автоматически не очищается.
