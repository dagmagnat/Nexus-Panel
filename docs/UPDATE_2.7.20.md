# Nexus Panel 2.7.20 — каталог узлов и автовыбор

В создании и редактировании профиля «Автовыбор» рядом с названием узла показаны способ подключения и ID: например, VLESS / TCP (RAW) / REALITY или VLESS / xHTTP / REALITY / auto. Это действует для основного пула и списков приоритетного/аварийного узла. Используется локальный кэш; если сведений нет, указано «транспорт не загружен». Для Remnawave без конкретного транспорта остаётся подпись API — её нельзя достоверно превратить в XHTTP/TCP без данных удалённого Host.

Кнопка «Добавить автоподключение» перенесена наверх рядом с «Добавить узел». На телефоне в навигации тоже есть отдельная ссылка.

В списке можно нажимать «Тип», «Транспорт», «Статус», «Активность»: первое нажатие — по возрастанию, второе — по убыванию, третье — исходный порядок. На телефоне используйте список «Сортировка». Статус сортируется по включению; активность — в сети, проверяется, нет данных, не в сети, отключён. Это состояния, не расход трафика и не измерение скорости.

Сортируется весь каталог, затем применяются страницы/фильтры. Это временный порядок просмотра; подписки не меняются. Пока сортировка включена, перетаскивание/стрелки изменения порядка отключены. Кнопка ↻ сбрасывает фильтры и сортировку. После сброса ручной порядок снова доступен.

## Обновление

Накопительный локальный патч для Nexus 2.7.7–2.7.19. Сохраните backup исходников, .env, баз и внешних control/workspace/DATA_DIR/volumes. Устанавливайте на сервер Nexus, не на VPN-ноду:

```bash
unzip Nexus-Panel-2.7.20-node-catalog-patch.zip -d /root/nexus-update-2.7.20
bash /root/nexus-update-2.7.20/apply-node-traffic-update.sh /opt/3xui-aggregator-vp
```

Укажите фактический каталог установки. Helper после preflight запросит YES, остановит aggregator, сохранит backup и пересоберёт. Сохранены ограниченные миграции Compose/Caddy из [2.7.17](UPDATE_2.7.17.md), требуется python3; весь Compose не заменяется. При изменении Caddy возможен краткий перерыв. Публикация на GitHub и установка на VPS не выполнялись.

После запуска проверьте docker compose ps/logs и редактор автовыбора, не удаляя старых подписок. Для systemd и отката используйте порядок из [2.7.19](UPDATE_2.7.19.md): остановить сервис, согласованный backup, перенос файлов PATCH_FILES.txt, npm ci --omit=dev, запуск; для отката восстановить один backup целиком и пересобрать.
