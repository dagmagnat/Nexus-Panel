# Nexus Panel 2.7.21 — окно обновления по центру

Окно «Обновление проекта» центрируется по обеим осям относительно экрана, независимо от прокрутки страницы. Крестик закрытия расположен внутри карточки. На небольшом экране карточка ограничена высотой окна; длинные технические сведения прокручиваются внутри. Изменены только два CSS-правила для этого окна, остальные диалоги и механизм обновления/host-updater не менялись.

Причина смещения: JavaScript открывает backdrop через display:flex, тогда как общий стиль центрирования рассчитан на grid. Добавлен justify-content:center; position:relative у карточки исправляет положение абсолютной кнопки закрытия.

## Установка на сервер Nexus

Накопительный локальный патч для 2.7.7–2.7.20. Перед установкой сохраните исходники, .env и базы; внешние DATA_DIR/control/workspace-каталоги и volumes копируйте отдельно.

```bash
unzip Nexus-Panel-2.7.21-update-modal-patch.zip -d /root/nexus-update-2.7.21
bash /root/nexus-update-2.7.21/apply-node-traffic-update.sh /opt/3xui-aggregator-vp
```

Укажите фактический каталог Nexus. Helper выполняет preflight, запрашивает YES, сохраняет backup и пересобирает. Известные ограниченные миграции Compose/Caddy из 2.7.17 сохранены, нужен python3; при изменении Caddy возможен краткий перерыв. Подробнее про systemd и откат — [инструкция 2.7.19](UPDATE_2.7.19.md). Не устанавливать на relay/exit вместо сервера Nexus. ZIP не публиковался и на VPS автоматически не устанавливался.

После установки обновите страницу браузера с перезагрузкой CSS. Не запускайте обновление сервера только ради проверки расположения окна.

## Проверка

Проверены 1920×1080, 1440×900, 390×844 и 844×390: центр карточки, отсутствие выхода за экран, крестик внутри, длинный открытый журнал, прокрутка страницы и повторное скрытие/открытие. До исправления воспроизводилось положение x=24 вместо центра; после тест проходит. Обновление сервера не запускалось. Это не проверка production host-updater или физического телефона.
