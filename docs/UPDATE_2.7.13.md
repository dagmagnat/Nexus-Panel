# Nexus 2.7.13 — несколько автоподключений

15 октября 2026. Локальный накопительный патч, на сервер пользователя не установлен и в GitHub не опубликован. Включает прежнюю оптимизацию, маршрутизацию Remnawave и служебный доступ 2.7.12.

## Изменения

Хранение нескольких профилей автовыбора и выдача их всех уже были предусмотрены. Ограничения «только один» в базе не было. Доработан интерфейс: отдельная кнопка «Добавить автоподключение», сразу нужный тип формы, после сохранения остаётся пустая форма для следующего профиля, кнопка «Создать ещё» рядом со списком. Создание не редактирует и не заменяет предыдущий профиль.

Браузерная проверка выявила и исправила реальную блокировку формы: старый обработчик авторизации повторно включал обязательный API Token у виртуального профиля. Нативный disabled-fieldset теперь исключает реквизиты панели из проверки и отправки в режиме автовыбора, даже если поздний обработчик меняет отдельный input. Для 3x-ui/Remnawave реквизиты остаются включёнными.

У каждого профиля собственные название/значок, основной пул, приоритетный и аварийный узлы, URL и интервал проверки. Один физический узел можно включать в несколько профилей. Редактирование, выключение и удаление действуют только на выбранный профиль, не удаляя серверы и клиентов.

## Как пользоваться

1. Узлы → «Добавить автоподключение».
2. Задать название, например «Европа», выбрать минимум два разных узла в совокупности основного пула/приоритета/резерва. В основном пуле нужен хотя бы один. Один узел нельзя одновременно назначать на разные роли внутри одного профиля.
3. Создать. Затем заполнить новое название и пул в оставшейся форме, например «CDN» или «Резерв», и создать следующий профиль.
4. В приложении обновить **JSON-подписку Nexus**, затем переподключиться. Все включённые профили с доступными клиенту узлами появятся отдельными подключениями перед обычными регионами.

Автовыбор работает на устройстве через Xray Observatory, не на сервере Nexus. Приложение должно поддерживать этот JSON. Обычный SUB/список VLESS не переносит балансировщики. Профиль не выдаёт узлы, к которым клиенту не назначен доступ; служебные узлы после истечения срока и лимиты не обходятся. Просроченной подписке обычные автопрофили не выдаются. Если у клиента доступен только один участник пула, профиль может содержать одного участника — нового доступа это не создаёт.

## Установка

Накопительный архив для Nexus 2.7.7–2.7.12. Если 2.7.12 ещё не установлен, отдельно ставить его не требуется. Сохранить полную резервную копию, включая внешние базы/volumes. На **сервере Nexus**, не на нодах, для стандартного Docker-развёртывания:

```bash
unzip Nexus-Panel-2.7.13-multiple-auto-connections-patch.zip -d /root/nexus-auto-2.7.13
cd /root/nexus-auto-2.7.13
bash apply-node-traffic-update.sh /opt/3xui-aggregator
```

Заменить `/opt/3xui-aggregator` фактическим каталогом Nexus. Helper требует YES, останавливает только aggregator, сохраняет весь каталог в backup рядом и пересобирает сервис. Внешние DATA_DIR/control/workspaces/volumes он сам не копирует. Правила серверной маршрутизации и удалённые панели не меняются.

Для systemd: остановить сервис, сохранить исходники и все базы/настройки, наложить PATCH_FILES.txt с путями, `npm ci --omit=dev`, запустить сервис. Откат: остановить сервис и восстановить исходники и базы из полной копии; локальный откат не отменяет удалённые операции предыдущих версий. Публичный установщик и `panel-script-v1.sh --update` этот неопубликованный патч не скачивают.

## Проверки

HTTP-тест создаёт три профиля с пересекающимися пулами, проверяет отдельные названия, интервалы, теги, все профили в JSON, сохранение физических регионов и SUB, изолированное редактирование/выключение/удаление, отказ при неверном пуле и без CSRF, сохранение после перезапуска. Актуализирован старый assertion балансировщика: явные selector-теги и blackhole fallback вместо уже отменённого принудительного первого узла. Боевой сервер и приложение на телефоне не тестировались.

Headless Edge: реальное создание ещё двух профилей кнопкой формы при 1440/390 px; переключения 3x-ui/Remnawave/автовыбор, поздний auth pass, отсутствие лишних реквизитов в POST, чистая форма после сохранения; без JS-ошибок и горизонтального переполнения. Целевой набор: 42 pass, 4 platform skip, 0 fail. Полный исторический набор: 199 pass, 9 прежних fail, 16 skip; не зелёный. JS, 20 EJS-шаблонов и bash-синтаксис helper проверены.
