# Telegram-бот: админское управление кнопками

В этой сборке администратору больше не обязательно вводить команды вручную для типовых действий.

## Что добавлено

- В админском меню появились кнопки `🔗 Привязать` и `📤 Выдать доступ`.
- Бот показывает Telegram ID пользователей, которые хотя бы один раз запускали бота или нажимали кнопку.
- Привязка работает по кнопкам: выбрать пользователя Telegram → выбрать клиента панели → бот привяжет и сразу отправит HAPP-доступ.
- В заявках появилась кнопка `🔗 Привязать заявку #ID`: Telegram ID берётся из заявки автоматически, администратору остаётся выбрать клиента.
- В поддержке появились кнопки `✍️ Ответить #ID` и `✅ Закрыть #ID`.
- Объявление можно отправить без команды `/announce`: нажать `📢 Объявление` и следующим сообщением отправить текст.

## Ограничение Telegram

Бот видит Telegram ID только тех пользователей, которые сами открыли бота и отправили `/start` или нажали любую кнопку. Если пользователь никогда не запускал бота, Telegram не отдаёт его ID боту, и бот не может написать ему первым.

## Ручные команды

Ручные команды остаются доступными как резервный способ:

- `/bind TELEGRAM_ID CLIENT_ID_OR_LOGIN`
- `/sendaccess TELEGRAM_ID [CLIENT_ID_OR_LOGIN]`
- `/orders`
- `/reply TICKET_ID текст`
- `/announce текст`
