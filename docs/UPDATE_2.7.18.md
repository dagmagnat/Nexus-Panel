# Nexus Panel 2.7.18 — переключатель формата ссылок

## Где включить или выключить

Откройте **Настройки → Общие настройки → Адреса панели и подписок**, измените галочку **«Чистые ссылки подписок — без /json/ и /sub/»** и нажмите **Сохранить**.

| Галочка | JSON | SUB |
| --- | --- | --- |
| Включена (по умолчанию) | `https://sub.example/ключ` | `https://sub.example/ключ?format=sub` |
| Выключена | `https://sub.example/json/ключ` | `https://sub.example/sub/ключ` |

По умолчанию сохранено поведение 2.7.17. Настройка хранится в базе своего рабочего пространства, сохраняется после перезапуска, входит в полный backup и профиль настроек. Старые открытые формы без нового поля не сбрасывают выбор. При переключении обновляется ревизия подписки.

Настройка меняет только выдаваемый адрес: копирование/QR в списке и редакторе пользователей (ПК и телефон), сводка клиента, Telegram и стандартная SUB/JSON-ссылка в публичном профиле. Настройки адреса/порта подписок применяются независимо. Для рабочих пространств сохраняется префикс `/s/<workspace>/`.

**Уже выданные ссылки обоих видов продолжают работать независимо от галочки.** Ключ клиента не меняется; заново добавлять подписку не требуется. Лимиты, HWID, срок, отключение клиента и запрет кэширования работают через общие обработчики. Это не способ отозвать старую ссылку и не защита от утечки ключа.

Короткие, нестандартные и зарезервированные ключи по-прежнему используют `/json/` и `/sub/` даже при включённой галочке. Специальные `/sub-plain/`, `/hiddify/`, `/happ/` и `/open/` не переименовываются. На публичной странице стандартная кнопка «SUB» учитывает переключатель; отдельная «SUB без метаданных» сохраняет прежний plain-формат. Импорт в INCY/Hiddify сохраняет специальные совместимые адреса. Ссылки исходных 3x-ui/Remnawave этот параметр не меняет.

## Обновление Docker-установки

Локальный накопительный патч для Nexus 2.7.7–2.7.17 с поддержкой рабочих пространств; ставится **на сервер Nexus**, не на CDN/relay/exit-ноды. Публикация на GitHub и установка на сервер этим выпуском не выполнялись.

Сначала сохраните полную копию Nexus, `.env` и баз. Внешние `DATA_DIR`, control/workspace-каталоги и Docker volumes сохраните отдельно: helper архивирует каталог установки, не весь VPS.

```bash
unzip Nexus-Panel-2.7.18-subscription-link-settings-patch.zip -d /root/nexus-update-2.7.18
bash /root/nexus-update-2.7.18/apply-node-traffic-update.sh /opt/3xui-aggregator-vp
```

Укажите фактический каталог своей установки. После проверки helper попросит `YES`, остановит aggregator, сохранит backup, перенесёт файлы и пересоберёт приложение. Порты, имена контейнеров и существующий Compose целиком не заменяются.

Сохранена [миграция установки 2.7.17](UPDATE_2.7.17.md): известный обязательный `build.network: host` заменяется на `default`, ограниченный Caddy-шаблон дополняется чистыми маршрутами. Только при изменении Caddy проверяется и пересоздаётся его контейнер; возможно краткое прерывание соединений. Нужен `python3`. Старый небезопасный ADMIN_PASSWORD отклоняется до остановки; реальный пароль существующего администратора в БД не сбрасывается. Произвольный внешний Nginx/Caddy автоматически не редактируется: для чистых URL он должен пропускать новый путь и query string, см. инструкцию 2.7.17.

После обновления:

```bash
cd /opt/3xui-aggregator-vp
docker compose ps
docker compose logs --no-color --tail=60 aggregator
```

Через 20–30 секунд проверьте, что контейнер остаётся Up, откройте настройки, выключите галочку и сохраните. Проверьте копирование JSON/SUB и QR у тестового клиента, затем включите обратно, если нужны чистые адреса. Старые подписки не удаляйте. Сброс браузерного/клиентского кэша не меняет сохранённый формат.

Для systemd: остановить сервис, сохранить согласованную копию исходников/баз, перенести файлы из `PATCH_FILES.txt` с сохранением путей, выполнить `npm ci --omit=dev` и запустить сервис. Проверить внешний прокси самостоятельно. Для отката остановить сервис, восстановить исходники/базы/.env/конфигурацию прокси из одного backup, пересобрать и запустить. Изменение одной галочки не требует отката всего выпуска.

## Проверки

Проверяются сохранение on/off настоящим HTTP POST, CSRF, отсутствие сброса старой формой, ревизия, отображение ссылок/QR, публичный профиль, сводка, оба вида маршрутов в обоих состояниях, перезапуск, независимые workspace-процессы с одинаковым ключом и перенос допустимого boolean в профиле настроек. Существующие проверки лимитов/HWID, DNS и UDP/443 сохранены.

Целевой набор: 51 тест, 42 pass, 9 platform skip, 0 fail. JS, 20 EJS и Bash-синтаксис проверены. Локальный headless Edge в production-режиме приложения: галочка и сохранение на размерах 1440/390, без ошибок JavaScript и горизонтального переполнения; снимки интерфейса просмотрены. Это не проверка на реальном телефоне.

Полный локальный набор: 252 теста, 226 pass, 9 прежних fail, 17 platform skip. Названия падающих тестов совпадают с 2.7.17 (Python PATH ×3, VM budget, устаревшие ожидания inbound/CSS/grace/device-grace/RBAC). Полный набор не зелёный; эти ошибки не объявлены исправленными. Логи `work/link-settings-*.log` не входят в архив. Реальный Linux/Docker/Caddy/VPS и мобильные приложения production не проверялись.
