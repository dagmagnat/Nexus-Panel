# Nexus Panel 2.7.2 — 8 сентября 2026

Локальный выпуск на основе предоставленного архива 2.7.0 и предыдущего
обновления активации. Публикация в GitHub и установка на рабочий сервер
автоматически не выполнялись.

## Изменения

- При формировании Remnawave-подписки запрашивается свежий пользовательский
  счётчик, даже если remote_sub_url уже сохранён. Используется текущее, не
  lifetime-потребление. Результат записывается в SQLite и сразу используется
  в имени сервера. Тайм-аут ограничен SUBSCRIPTION_STATS_TIMEOUT_MS (3,5 с
  по умолчанию); при ошибке API выдача использует прежнее значение.
- Настройка subscription_live_usage соблюдается. При её отключении расход
  остаётся из кэша до отдельного обновления статистики. Значение в названии
  приложения меняется после обновления подписки, не после каждого пакета;
  округление тоже может временно оставлять видимое значение прежним.
- Исправлена лишняя строка у мобильного автовыбора: поздний CSS повторно
  показывал скрытый drag handle. Скрытие сделано адресно для мобильной версии.
- Центрированы мобильные QR, обычные диалоги, загрузка и редакторы.
  Длинные окна ограничены высотой экрана и прокручиваются внутри.
  UUID занимает отдельную короткую строку, SUB/JSON и QR — две компактные
  соседние карточки. Размеры кнопок оставлены пригодными для нажатия.
- На ПК высокий заголовок убран только у активного списка узлов. Управление
  темой сохранено. Правая панель получила дополнительную высоту; при очень
  маленьком экране или большом количестве полей прокрутка сохранена, чтобы
  не скрывать информацию.
- В редакторе узла убраны конфликтующие span-8/span-4: раньше они создавали
  неявные колонки внутри двухколоночной сетки. На ПК поля слева, предпросмотр
  и пояснения справа. На телефоне одна колонка. Увеличен шрифт полей редактора.
- Nexus Node по умолчанию выключен (NEXUS_NODE_ENABLED=0), не устанавливается
  вместе с панелью и не показывается в меню. Исходники и ранее созданные
  записи оставлены. Эксперимент включается только вручную через окружение;
  ни остановка, ни удаление ранее установленных служб этим не выполняется.
- Ранее добавленная отложенная активация клиента включена в эту сборку.

## Проверки и границы

13 тестов: 7 существующих сценариев активации и 6 новых сценариев расхода
Remnawave. Все 17 EJS-шаблонов компилируются. В браузере Edge проверены
реальные шаблоны с синтетическими данными на ширинах 390, 576, 1366, 1920:
границы страницы, высота автовыбора, колонки редактора, изменение предпросмотра
и центрирование QR/загрузки/редактора клиента. Тестовый QR заменён картинкой,
проверялось расположение окна, не сканирование кода.

API вашего Remnawave, серверная база и логи не были доступны. Подтверждён и
исправлен дефект кода, способный объяснить застывшие 0,3/50 ГБ; утверждать,
что иных причин на конкретном сервере нет, нельзя. После установки проверьте
расход в Remnawave и вручную обновите подписку в приложении. При расхождении
потребуются обезличенный ответ API пользователя и лог ошибки обновления
статистики — без токенов и ссылок подписки.

Это не исправление всех пунктов аудита: надёжность экспериментального агента,
полнота JSON-backup и поведение trial при недоступных узлах требуют отдельной
работы. Полный HTTP-прогон с реальной базой, Docker-сборка и Linux/systemd здесь
не выполнялись. Среда локальной проверки — Windows/Node.js 24; рабочая версия
проекта остаётся Node.js 22.
