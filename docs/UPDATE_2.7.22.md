# Nexus Panel 2.7.22 — приоритет VPN и удаление узлов

## Российский сайт через VPN при RU/direct-исключениях

Откройте **Маршрутизация → Всегда через VPN — приоритет над direct**. Общий блок виден независимо от выбранного режима. Например:

```text
Домены:
domain:example.ru
full:service.example.ru

IP:
203.0.113.10/32
203.0.113.0/24
```

Это примеры, не адреса нужного вам сервиса. Замените их своими. domain включает поддомены, full задаёт точное имя; IP принимает IPv4/IPv6/CIDR/GeoIP. По одному правилу в строке. Если известен домен, добавляйте его: IP-правило само по себе не выбирает DNS для доменного имени.

Включите маршрутизацию и назначьте нужные узлы режиму «Выбранный через proxy кроме…». Приоритет: блокировки → список VPN → direct-исключения → оставшийся трафик через VPN. Поэтому указанный российский домен/IP пойдёт через VPN раньше category-ru/geoip:ru. При отдельном direct DNS приоритетные proxy-домены сначала используют основной DNS; при сбое возможен обычный DNS fallback.

В режиме «Выбранное через proxy» этот же общий список определяет выбранный VPN-трафик, остальной идёт напрямую. Существующие custom_domains/custom_ips и правила не сбрасываются. Механизм приоритетов уже был в генераторе, но поля находились внутри скрытого второго режима; в этом выпуске они вынесены наружу, без дублирования.

**Сохраните и обновите JSON-подписку в приложении.** Это клиентская JSON-маршрутизация выбранных 3x-ui/Remnawave-узлов, включая JSON автовыбора. Обычные VLESS/SUB не передают эти правила; отдельный Happ-профиль и серверные конфигурации не изменяются. Блокировка самого IP VPN-сервера этим правилом не устраняется. Замена адресов VPS не выполнялась: новые IP не предоставлены.

## Удаление подключения без редактора

В «Узлы» выберите строку и нажмите **Удалить** в карточке справа. На телефоне раскройте строку — кнопка находится рядом с остальными действиями. Подтверждение показывает ID подключения и предупреждает об исчезновении из подписок.

Операция локальная: ответ недоступного/заблокированного сервера не требуется. Удаляется подключение Nexus; VPS и аккаунты в удалённой панели не удаляются, остальные пользователи/узлы Nexus сохраняются. Восстановление подключения может потребовать повторной настройки и привязок — перед удалением сохраните backup. У виртуального автовыбора остаётся его собственное удаление профиля. POST/CSRF/права доступа не менялись.

## Установка

Локальный накопительный патч для Nexus 2.7.7–2.7.21; ставить на сервер Nexus, не на relay/exit:

```bash
unzip Nexus-Panel-2.7.22-priority-vpn-delete-patch.zip -d /root/nexus-update-2.7.22
bash /root/nexus-update-2.7.22/apply-node-traffic-update.sh /opt/3xui-aggregator-vp
```

Укажите фактический каталог. До установки сохраните исходники/.env/базы и отдельно внешние DATA_DIR/control/workspace/volumes. Helper делает preflight, запрашивает YES, сохраняет backup и пересобирает. Сохранены ограниченные миграции Compose/Caddy (нужен python3); при изменении Caddy возможен краткий перерыв. Порядок systemd/отката — [2.7.19](UPDATE_2.7.19.md). Патч не опубликован и на сервер автоматически не установлен.

Edge 1440/390 в production-фикстуре: видимость полей, удаление в desktop/mobile, отмена сохраняет узел, подтверждение удаляет локально. Это локальный браузер, не физический телефон и не реальный VPS.
