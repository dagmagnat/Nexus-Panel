# Восстановление после MODULE_NOT_FOUND: ./lib_access

12 сентября 2026.

По журналу Nexus завершает запуск на `require('./lib_access')`, контейнер
перезапускается, и Caddy возвращает 502. Это не ошибка сертификата и не
подтверждение нехватки памяти. Предупреждение о коротком ADMIN_PASSWORD
не является причиной остановки.

Этот архив объединяет изменённые файлы двух предыдущих патчей:
`Nexus-Panel-users-preferences-pilot` и `Nexus-Panel-quotas-ui-fix`.
При совпадении файлов взята версия из последнего патча лимитов/интерфейса.
Это НЕ полный проект; устанавливается поверх Nexus 2.7.5 с предшествующими
исправлениями. Два указанных патча отдельно устанавливать больше не нужно.
Базы данных, .env, пароли, клиенты и узлы в архив не включены.

## Установка через GitHub и agg

1. Сохраните резервную копию каталога данных и .env. Не удаляйте существующие
   базы и не выполняйте переустановку сервера.
2. Загрузите ВСЁ содержимое этого архива в корень вашего проекта GitHub,
   сохранив каталоги views, public и tests. Не создавайте вокруг файлов
   дополнительную папку. Файлы lib_access.js, lib_access_routes.js,
   lib_workspace_runtime.js и lib_settings_profile.js должны лежать рядом
   с app.js. Не пропустите скрытый файл .dockerignore.
3. На сервере выполните agg и выберите пункт 2: обновление с сохранением данных.
   В выборе дополнительных панелей оставьте 0 — оставить как есть.
   Нужна пересборка образа приложения: простой docker restart не добавляет
   отсутствующие файлы в существующий образ.
4. Проверьте:

```bash
docker ps -a --format "table {{.Names}}\t{{.Status}}"
docker logs --tail 60 3xui-aggregator
```

Если имена контейнеров отличаются, используйте имя Nexus из первой команды.
Если контейнер снова перезапускается, пришлите новый журнал без паролей и
токенов. Не удаляйте control.db или app.db для обхода ошибки.

## Проверки и ограничения

Повторно пройдены 12 целевых тестов: миграция существующей базы, права,
разделение пространств, HTTP-запуск процессов, профили настроек и сохранение
лимитов узлов. Проверка на вашем VPS не выполнялась.

Новых функций в этом архиве нет: исправлена комплектность поставки.
Пользователи/пространства остаются пилотной реализацией с ограничениями,
описанными в PATCH-USERS-PREFERENCES.md. Указание в PATCH-QUOTAS-UI.md
об отдельной установке предыдущего патча относится к старому архиву;
здесь необходимые файлы уже включены.
