# Nexus Panel 2.0.2 — исправление маршрутизации и мобильного входа

Небольшой патч поверх Nexus Panel 2.0.1. Он содержит только изменённые файлы и не заменяет `data/`, `.env`, клиентскую базу, UUID, `sub_slug` или ссылки подписок.

## Исправлено

- форма маршрутизации больше не сжимается в вертикальные полосы;
- левая форма и правый итог используют устойчивую сетку 3:2, на телефоне — одну колонку;
- критическая сетка встроена также непосредственно в страницу и сработает даже при старом CSS в кеше;
- Spectrum CSS и `site.webmanifest` получили новую ревизию и заголовки запрета кеширования;
- PWA и ярлык телефона запускаются через `/mobile-login`;
- старый `/login` и сохранённые закрытые страницы после потери сессии показывают вход вместо `Not found`;
- пароль администратора, admin IP и блокировка перебора продолжают действовать.

## Установка

```bash
mkdir -p /root/nexus-hotfix-2.0.2
unzip -o /root/Nexus-Panel-2.0.2-routing-mobile-login-changed-files.zip \
  -d /root/nexus-hotfix-2.0.2
cd /root/nexus-hotfix-2.0.2
bash apply-spectrum-clear.sh
```

Скрипт создаёт резервную копию заменяемых файлов и базы в `/opt/3xui-backups/`, не изменяет `data/` и `.env`, затем пересобирает контейнер. При ошибке сборки выполняется автоматический откат файлов.

После обновления достаточно один раз открыть адрес панели. Старый мобильный ярлык будет перенаправлен автоматически; переустанавливать ярлык не требуется.
