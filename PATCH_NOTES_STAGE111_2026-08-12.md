# Stage 111 — безопасное обновление старой установки

Дата: 2026-08-12  
Версия: `stage111-safe-legacy-update-1.0.7-2026-08-12`

## Причина

Старая установка могла иметь Git `origin`, указывающий на `dagmagnat/3xui-Aggregator`. Хотя новый конфигурационный источник уже мигрировал на `dagmagnat/Nexus-Panel`, команда `git fetch --all` продолжала обращаться к старому origin и останавливалась на запросе имени пользователя GitHub. Контейнеры при этом уже были выключены.

## Исправление

- выбранный репозиторий скачивается напрямую независимо от старого origin;
- интерактивные запросы Git отключены;
- контейнеры останавливаются только после успешного получения и проверки commit;
- после успешной загрузки origin переключается на Nexus Panel;
- при ошибке загрузки стек продолжает работать, исходные файлы и данные не меняются;
- `data/`, `.env`, `.install.conf` и `.source.conf` сохраняются.

## Безопасный переход

1. Загрузить все файлы Nexus Panel в ветку `main` репозитория `dagmagnat/Nexus-Panel`.
2. Создать резервную копию через `agg` → пункт `5`.
3. Запустить актуальный `install.sh` с аргументом `update`.
4. Проверить `docker compose ps`, вход в панель и число клиентов.

Пункты «Новая установка» и «Переустановить заново» для обычного перехода не нужны.
