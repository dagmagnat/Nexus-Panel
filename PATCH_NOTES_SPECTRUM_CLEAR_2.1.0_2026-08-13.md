# Nexus Panel 2.1.0 — compact mobile workspace

Обновление предназначено для установленной Nexus Panel 2.0.2 Spectrum Clear и заменяет только файлы интерфейса и метаданные версии.

## Что изменено

- оставлена одна мобильная навигация: при выбранном нижнем меню кнопка-гамбургер сверху скрыта;
- раздел «Ещё» стал компактной сеткой 2×2;
- с дашборда убран повторный блок состояния узлов, быстрые действия собраны в компактную сетку;
- страница узлов автоматически обновляет активность раз в 60 секунд;
- мобильный список клиентов показывает короткие строки со статусом, сроком и комментарием;
- нажатие по строке клиента открывает подробности без перезагрузки и без потери позиции списка;
- массовые действия с клиентами свёрнуты до момента выбора;
- карточки узлов, шрифты, статусы и кнопки порядка уменьшены;
- маршрутизация на телефоне разделена на вкладки «Настройка» и «Текущий итог».

## Безопасность данных

Патч не содержит миграций базы и не заменяет `data/` или `.env`. UUID, `sub_slug`, сроки, лимиты, назначение узлов и уже выданные ссылки клиентов сохраняются. Перед копированием файлов скрипт делает резервную копию базы и всех заменяемых файлов.

## Установка

```bash
mkdir -p /root/nexus-mobile-2.1.0
unzip -o /root/Nexus-Panel-2.1.0-mobile-workspace-changed-files.zip -d /root/nexus-mobile-2.1.0
cd /root/nexus-mobile-2.1.0
bash apply-spectrum-clear.sh
```

После запуска дождитесь успешной Docker-сборки и откройте панель заново. Ревизия CSS `v=210` заставит браузер загрузить новый интерфейс.
