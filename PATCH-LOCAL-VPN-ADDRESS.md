# Исправление публичного адреса локальной 3x-ui

Причина: hostname внутреннего API `http://local-3xui:2053` использовался как
адрес VPN в клиентской подписке, если inbound не задавал отдельный Share address.

Теперь мастер передаёт публичный VPN-адрес в Nexus отдельно через
`NEXUS_LOCAL_XUI_PUBLIC_HOST`. Для существующей установки по IP адрес берётся
из сохранённого состояния локальной панели. В новом мастере для доменного
режима можно указать отдельный прямой IP/DNS для VPN. Изменение домена
административной панели через меню сертификатов сохраняет VPN-адрес.
Явно настроенный Share address inbound имеет приоритет. Удалённые панели
не используют адрес локальной установки.

## Применение

1. Замените файлы из архива в репозитории Nexus, сохранив пути.
2. На сервере выполните обычное обновление Nexus через меню `agg`.
   Нужны и пересборка приложения, и повторная генерация Compose-конфигурации:
   простой перезапуск старого контейнера или замена одного app.js недостаточны.
3. Оставьте API Panel URL узла `http://local-3xui:2053` и прежний Panel Path.
4. Обновите подписку в клиентском приложении. Пересоздавать клиента не нужно.

Для нестандартной установки без мастера задайте переменную окружения Nexus
вручную либо явный публичный Share address в inbound. Не используйте Docker-имя
или домен за обычным HTTP CDN в качестве VPN-адреса. Не меняйте Reality SNI
на публичный IP: SNI и адрес подключения имеют разные назначения.

## Отдельно проверьте порт

В присланной конфигурации клиент использует порт 28140, а в более раннем
выводе установщика были опубликованы 32669/tcp и 32669/udp. Если публикация
не менялась, исправление адреса не устранит несовпадение портов. Порт inbound
должен соответствовать опубликованному VPN-порту Docker, либо нужно
опубликовать фактически используемый порт. HTTPS-порт панели 2053 для этого
не подходит. Патч не меняет inbound и порты автоматически.

## Проверки

- 5 тестов выбора адреса и реального генератора VLESS-ссылки.
- 5 регрессионных тестов адреса API.
- 52 теста мастера локальных панелей с имитацией Docker.
- Синтаксическая проверка app.js.

Живой Docker/VPS и фактическое VPN-соединение в этой среде не проверялись.
