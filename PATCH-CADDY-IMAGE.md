# Исправление загрузки Caddy

Для режима публичного IP-сертификата образ caddy:2.11.0 заменён на
caddy:2.11.4. Тег 2.11.4 указан в официальном каталоге Docker:
https://raw.githubusercontent.com/docker-library/official-images/master/library/caddy

Перед остановкой существующего стека установщик проверяет сохранённое состояние
локальных панелей. Если используется публичный IP-сертификат, сначала выполняется
docker pull caddy:2.11.4. При ошибке загрузки или чтения состояния остановка
отменяется. Защита относится к этому образу; ошибки последующей сборки Nexus
не покрываются этой проверкой. Уже остановленный прежней версией стек она
автоматически не восстанавливает.

## Применение

1. Загрузите файлы архива в корень своего GitHub-репозитория с сохранением путей.
2. Запустите свежий установщик: старый локальный agg может ещё использовать
   старую логику. В SSH под root:

```bash
curl -fsSL https://raw.githubusercontent.com/dagmagnat/Nexus-Panel/main/bootstrap.sh | bash -s -- menu
```

3. Выберите «Обновить проект, сохранив данные». Если появится вопрос о
   дополнительных панелях, 0 сохраняет существующие настройки.

Обновление заново сгенерирует Compose override с исправленным образом.
Переустанавливать ОС или удалять базы/тома не требуется. UUID, VPN-порты,
логины и настройки сертификатов этим патчем не меняются. Предварительно
сохраните резервные копии Nexus и отдельно /opt/nexus-local-panels/<instance>.

Проверено: 56 Python-тестов, 14 Node/Bash-тестов, bash -n install.sh.
Тесты Docker используют имитацию команд; живой VPS и выпуск сертификата
в этой среде не проверялись.
