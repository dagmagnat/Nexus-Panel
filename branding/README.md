# Nexus Panel logo assets

- `nexus-logo-master.png` — исходный PNG 1254×1254 с прозрачным фоном.
- `public/img/nexus-logo.png` — основной веб-логотип 512×512.
- `public/img/nexus-logo-192.png` и `public/img/nexus-logo-512.png` — иконки manifest.
- `public/apple-touch-icon.png` — иконка Apple Home Screen.
- `public/favicon.ico` — favicon 16–256 px для вкладки браузера.

Знак представляет букву N, собранную из сетевых маршрутов внутри защищённого контура. Цвета: graphite/navy, cobalt blue, cyan и violet.

Мастер-файл имеет настоящий прозрачный фон и достаточный безопасный отступ для круглых и квадратных масок. Если логотип меняется, нужно заново подготовить все размеры из этого списка, чтобы браузер, iOS и Android не использовали старые варианты.
