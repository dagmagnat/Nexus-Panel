# Формы пользователей, профиль настроек и закреплённые вкладки

12 сентября 2026. Только изменённые/новые файлы поверх последнего патча
Nexus-Panel-access-recovery-dialog. Не полный проект.

## Изменения

- На страницах «Пользователи и доступ» и «Профиль настроек» выделяется их
  собственный пункт меню, а не «Настройки».
- Вместо общей 12-колоночной form-grid введены отдельные сетки: два столбца
  на широком экране, один на телефоне. Поля больше не занимают случайную 1/12
  ширины. Кнопки не растягиваются по высоте соседнего описания.
- Права оформлены читаемыми карточками с флажками; пояснения и кнопки
  сохранения занимают отдельную строку. Ссылка экспорта выглядит как кнопка.
- Вкладки настроек не переносят последнюю кнопку в одинокую вторую строку:
  при нехватке ширины используется горизонтальная прокрутка.
- Отступ закреплённых вкладок вычисляется из реальной высоты видимой шапки,
  обновляется при изменении ширины, масштаба и высоты текста. Шапка не должна
  перекрывать вкладки. Обработчики форм, роли и данные не менялись.

## Применение

Сделайте резервную копию. Загрузите всё содержимое архива в корень проекта
GitHub, сохраняя каталоги public, views и tests. Выполните agg → 2, для
дополнительных панелей выберите 0. Перезагрузите страницу Ctrl+F5.
Обязательно загрузите оба новых файла public/css/management-layout.css и
public/js/management-layout.js вместе с шаблонами.

## Журнал и ресурсы сервера

В предоставленном снимке Nexus запущен, использует около 74 MiB RAM (3,75%
лимита 1,922 GiB), CPU 38,59%. Этот снимок не показывает нехватку памяти
контейнера Nexus, но не исключает нагрузку хоста, ожидание сети или пики.
Причина медленной работы по одному снимку не установлена.

Ошибка расшифровки panel_access_key означает, что зашифрованное значение не
прошло проверку подлинности при использовании текущего APP_SECRET. Возможны
другой ключ после обновления/восстановления или повреждённое значение.
Она не связана с размером кнопок. Код при этой ошибке берёт резервное значение
настройки; в данном журнале запуск продолжился на порту 3000.

Не меняйте APP_SECRET на новый: это может сделать другие сохранённые секреты
недоступными. Нужна проверка соответствия текущего APP_SECRET тому, с которым
была создана база (например, по прежней резервной копии .env). Сам секрет и
содержимое .env в чат не присылайте. Этот патч не сбрасывает и не переписывает
секреты; исправление данных без подтверждённого правильного ключа не выполнялось.

шаблонов, расчёт отступа шапки, отсутствие регрессии окна отказа.
