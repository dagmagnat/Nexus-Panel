# Nexus Panel 2.2.1 — компактная мобильная панель

## Что исправлено

- У мобильных карточек клиентов возвращена цветная линия состояния слева:
  зелёная — клиент активен, жёлтая — срок скоро закончится, красная — срок
  истёк или клиент отключён.
- Массовые операции больше не занимают экран постоянно. После выбора хотя бы
  одного клиента появляется кнопка `Действия`, которая открывает компактные
  операции удаления из узла и из агрегатора.
- На телефоне скрыты дублирующие верхние поиск и блок статистики клиентов.
  Остаётся рабочий поиск каталога и одна строка из четырёх фильтров:
  `Все`, `Активные`, `Истекают`, `Отключены`.
- Редактор клиента уплотнён: подписи и значения разделены, UUID переносится
  целиком, выбор узлов выровнен по центру, второстепенное описание скрыто только
  на телефоне.
- Исправлена мобильная таблица SNI-профилей: домены больше не выводятся по одной
  букве в строке, встроенные профили не создают пустую кнопку действия.
- Кнопка сохранения настройки панели получила нормальную ширину, а разделы
  `Перенаправление`, `Диагностика` и `TG-бот` собраны в компактную сетку.
- Карточки раздела `Ещё` на телефоне отображаются по две в строке без длинных
  описаний.
- Заголовок списка узлов больше не растягивается на высоту экрана. Карточки
  узлов стали плотнее, а число потраченных ГБ удалено из подписи транспорта.
- Обновлён ключ кеша стилей до `v=221`, поэтому телефон получает новую версию
  CSS сразу после обновления.

## Что не меняется

Патч не содержит миграций базы и не заменяет `data/`, `.env`, `.install.conf`
или `.source.conf`. Клиенты, UUID, `sub_slug`, SUB/JSON-ссылки, сроки, лимиты,
связи с узлами, API-токены и параметры установки сохраняются.

Перед заменой файлов установщик копирует `data/app.db` и каждый заменяемый файл
в `/opt/3xui-backups/spectrum-clear-2.2.1-*`. Если проверка или Docker-сборка
завершится ошибкой, прежние файлы возвращаются автоматически.

## Установка

```bash
mkdir -p /root/nexus-spectrum-2.2.1
unzip -o /root/Nexus-Panel-2.2.1-mobile-density-actions-changed-files.zip \
  -d /root/nexus-spectrum-2.2.1
cd /root/nexus-spectrum-2.2.1
bash apply-spectrum-clear-2.2.1.sh
```

После успешной сборки полностью закрой старую вкладку панели на телефоне и
открой сохранённый адрес входа снова. Благодаря `v=221` дополнительная очистка
кеша обычно не требуется.

## Откат

Точная команда будет напечатана установщиком. Пример:

```bash
bash /opt/3xui-backups/spectrum-clear-2.2.1-ДАТА/rollback-spectrum-clear-2.2.1.sh \
  /opt/3xui-backups/spectrum-clear-2.2.1-ДАТА
```
