# Stage 112 — перенос клиентов между серверами

Версия: `stage112-client-transfer-1.0.8-2026-08-12`

## Что добавлено

- Экспорт клиентов напрямую из `data/app.db`, даже если старая панель не открывается.
- Импорт и экспорт через SSH (`agg clients ...`) и через страницу клиентов Nexus Panel.
- Сохранение логина, UUID, `sub_slug`, сроков, лимитов, комментариев, трафика и локальных связей.
- Проверка SHA-256, транзакционный dry-run и автоматическая копия базы перед записью.
- Безопасные конфликты `skip`, `update`, `replace` и привязки узлов `none`, `match`, `selected`.

## Важные гарантии

- Пароли узлов, токены API и другие секреты подключения не экспортируются.
- Импорт не отправляет запросы на удалённые 3x-ui или Remnawave-серверы.
- `update` не заменяет UUID или `sub_slug`, если совпал только логин.
- При прежнем домене сохранённый `sub_slug` оставляет старую ссылку подписки действующей после смены DNS.

## Минимальный перенос

```bash
# Старый сервер
agg clients export /root/nexus-clients.json

# Новый сервер: сначала только проверка
agg clients import /root/nexus-clients.json --dry-run

# Затем запись без автоматической привязки к узлам
agg clients import /root/nexus-clients.json --mode update --node-mode none
```

Подробности находятся в разделе «Перенос клиентов на новый сервер» файла `README.md`.
